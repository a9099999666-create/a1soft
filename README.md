# A1Soft

Студия цифровых продуктов: сайт, пошаговый бриф и очередь заявок.

Заявка с формы сразу попадает в кабинет «Студия». Данные живут в браузере (localStorage), без аккаунта и без почтовой рассылки. На первом заходе очередь заполняется двумя демо-карточками — они помечены бейджем «демо».

## Как пользоваться

1. Откройте главную и пройдите услуги и кейсы.
2. Соберите бриф: кто вы, какая поломка, срок и бюджет.
3. Откройте «Студия» — заявка уже в очереди. Смените статус или удалите карточку.

Пустая очередь — отдельный экран: можно собрать новый бриф или вернуть демо-заявки.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm start
```

Стек: Next.js, TypeScript, Tailwind CSS, shadcn/ui.
